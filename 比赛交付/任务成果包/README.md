## 文件与字段

| 文件 | 内容 |
|---|---|
| task1_learning_requirements.* | 主题 T01–T03 / 观察指标 / 课标编号与页码 / 教材页码 / 题目 Q / 学习卡 L / 教材切片 B |
| task2_individual_analysis.* | 学生 × 观察指标：记录数、有效记录、待评分、未作答、异常排除、得分率、满分率、部分得分率、诊断状态、证据记录 ID |
| task2_group_analysis.* | DC01/DC02 × 主题 × 指标统计 |
| task3_learning_recommendations.* | 个性化建议：学习卡/教材/练习题目、实施顺序、提示方式、调整条件、后续观察 |
| case_studies.json | 三名代表性案例（部分得分/表现较好/记录不足）+ 双班比较 |
| data_quality_report.* | 修订版本、未作答、待评分、分数异常、节点越界，含处理状态与是否进入统计 |
| field_spec.* | 字段名、类型、含义、必填、关联 ID、缺失表示、数据来源、示例 |
| dataset_manifest.json | 数据集清单、源文件 SHA-256、分析范围与计数 |
| source_data/ | 官方源 CSV 副本（只读，不改原值） |

## 口径与限制

- 原始作答 806 行；按“同一作答事件取最新修订版本”得到分析记录 799 条；历史版本保留在数据质量报告中。
- 原始评分状态：已评分 795 / 待评分 6 / 未作答 5；未作答、待评分不进入错误率/掌握率分母。
- 4 条异常记录（3 条分数异常、1 条节点越界）被标记并排除出正式统计，未静默修正。
- 官方 4 个未明确项：独立评测数据的具体文件、成果包模板、教师身份与案例指定名单，需团队/赛方确认（详见设计文档）。
- 本成果包仅使用主办方模拟数据，不含真实学生个人信息。
