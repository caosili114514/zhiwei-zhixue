# 知微·智学 · 比赛交付运行说明

## 1. 运行
- 方式 A：双击 `启动知微智学.bat`，或 `node server.mjs`，打开 `http://127.0.0.1:5178/`。
- 方式 B：直接双击 `index.html`（演示模式兼容 file://；赛题数据模式建议使用本地服务）。
- 零依赖、零构建；推荐 Edge / Chrome 桌面浏览器。

## 2. 两种数据模式
- **演示数据**：原有 11 名学生 / 206 条作答，用于功能演示与回归测试。
- **赛题数据**：主办方模拟数据（DC01/DC02、40 名学生、806 条原始作答），独立存储，不污染演示数据。
- 切换：右上角用户菜单 → “数据模式” → 赛题数据/演示数据。也可用 URL：
  - 赛题成果：`?role=teacher&data=official#/teacher/contest`
  - 赛题工作台：`?role=teacher&data=official#/teacher/dashboard`
  - 学生端：`?role=student&user=D01&data=official#/student/home`
- 重置：用户菜单 → 重置当前模式数据（恢复初始导入；不会删除另一种模式）。

## 3. 比赛成果页（教师端 → 教学支持 → 赛题成果）
- Task 1：学习内容与要求表（主题/指标/课标页码/教材页码/题目/学习卡/教材切片）。
- Task 2：DC01/DC02 班级对比、数据质量报告（修订/未作答/待评分/异常）、学生个体分析。
- 典型案例：自动筛选 3 名代表性学生（部分得分/表现较好/记录不足），含证据、诊断、建议、后续观察。
- 成果包：导出全部成果包（JSON/CSV/字段说明/manifest/README）或按文件导出。
- 导出为浏览器下载；若多文件下载被拦截，请允许本站点下载或分批导出。

## 4. 自检命令
```bash
node tests/check-data.mjs        # 原有演示数据 53 项
node tests/check-official.mjs    # 官方数据/质量/成果 13 项
node tests/smoke.mjs             # 12 路由 + 权限 2/2
node tests/smoke.mjs --print     # 打印 3/3
node _dsh_work/gen-outcomes.mjs  # 重新生成任务成果包
```

## 5. 数据与成果位置
- 官方源数据：`data/official/`（只读副本；原始 ZIP 由主办方提供）。
- 生成脚本：`js/data/official-data.js`（由 CSV 生成）、`js/data/official.js`（适配 state）、`js/services/competition.js`（Task1/2/3、质量、案例、成果包）。
- 成果包：`_dsh_work/比赛交付/任务成果包/`。
- 设计文档：`_dsh_work/比赛交付/设计方案.pdf`（≤20 页）。
- 答辩 PPT：`_dsh_work/比赛交付/答辩PPT.pptx`。
- 演示视频脚本：`_dsh_work/比赛交付/演示视频脚本.md`。

## 6. 口径与限制
- 原始 806 行 → 按作答事件取最新修订版 799 条分析记录；历史版本保留。
- 原始状态 795/6/5（已评分/待评分/未作答）；未作答、待评分不计为答错。
- 4 条异常记录（3 分数异常 + 1 节点越界）标记并排除正式统计，不静默修正。
- 数据为模拟数据，不用于证明真实教学成效；未接入真实 OCR/大模型，界面已标注。
- 仅使用主办方模拟数据，不含真实学生个人信息；赛后按赛方要求删除。
