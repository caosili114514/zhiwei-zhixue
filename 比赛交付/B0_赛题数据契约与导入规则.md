# B0 · 赛题数据契约与导入规则

> 依据：主办方 `4_赛题数据/模拟学情数据/字段说明.csv`、`赛题数据说明.docx`、`1_赛题规则.pdf`；本文件为实施契约，不修改原始数据。

## 1. 官方表 → 内部 state

| 官方表 | 内部位置 | 关键映射 | 缺失/异常 |
|---|---|---|---|
| 课程要求 | `chapters`（T01–T03）+ `knowledgePoints`（T01I1–T03I3） | 主题/目标/观察指标/课标编号/课标页/教材页 | 缺失阻断；标记待确认 |
| 题目与材料 | `questions`（Q）+ `materials`（L/B） | 题型、题干、选项、答案、解析、满分、评分点、指标、主题、来源 | 非题目材料不进入 questions；教材未标主题允许 |
| 模拟学生 | `users` + `classes` | 学生编号/班级/年级；DC01/DC02 | 未知班级隔离 |
| 测验节点 | `tasks`（按节点×班级）+ `papers` | 节点日期、已教主题、可用题列表 | 越界题隔离（已有 1 条） |
| 作答记录 | `answers` + `answerHistory` + `dataQuality` | 事件/修订、状态、分数、最终作答、解答过程、评分点得分 | 多版本取最新；未作答/待评分/异常标记 |

## 2. 版本与状态规则

- **修订**：同一 `作答事件编号` 按 `修订版本` 最大值；版本冲突按提交时间较晚者；历史版本保留，不重复计数。
- **状态**：`已评分 → answered/auto`；`待评分 → answered/suggested`（无分，待定）；`未作答 → unanswered/unjudged`（缺失，不判错）。
- **统计**：有效记录 = 有得分且未被标记异常；未作答、待评分、异常记录不进入错误率/掌握率分母。
- **异常**：分数越界、评分点合计≠总分、题目不在节点可用列表 → 标记 `excludeFromStats`，写入 `dataQuality.issues`，不静默修正。
- **知识点/指标不确定**：不进入正式诊断；相关题目标记 `indicatorId` 待确认（当前官方数据全部可映射）。
