# 录屏操作手册（MP4，≤5 分钟）

> 目标：录制 4:40–5:00 的演示视频，覆盖“三项任务 + 典型案例 + 依据查看 + 成果包”。本文件为操作步骤，不代替实际录制。

## 一、录屏前准备

1. 关闭无关浏览器标签/扩展；屏幕分辨率建议 1920×1080；浏览器缩放 100%。
2. 启动项目：
   ```bash
   cd E:\人工智能+创新大赛
   node server.mjs
   ```
3. 浏览器打开：`http://127.0.0.1:5178/index.html?role=teacher&user=T01&data=official#/teacher/contest`
4. 提前生成成果包：`node _dsh_work/gen-outcomes.mjs`，并打开 `比赛交付/任务成果包/` 备用。
5. 检查顶栏徽标为“赛题数据”，避免录到演示数据。
6. 准备录屏软件（OBS / Windows 游戏录制 / PPT 录制均可），开启麦克风；建议先录 10 秒试音。

## 二、分镜与操作（建议总时长 4:40）

| 时间 | 页面 | 具体操作 | 口播要点 |
|---|---|---|---|
| 0:00–0:20 | 赛题成果页 | 停留在 Task1 | 项目名称、三项任务、官方 40 学生/806 条/2 班 |
| 0:20–0:50 | Task2 → 数据质量报告 | 点击 Task2；展开“数据质量报告” | 806→799（7 修订）；795/6/5；3 分数异常、1 节点越界；未作答/待评分不判错 |
| 0:50–1:30 | Task1 | 滚动主题/指标表；展开学习卡清单 | 3 主题、9 指标、课标/教材页码、Q/L/B 关联 |
| 1:30–2:20 | Task2 | 看双班表；学生选择 D04；看指标状态与证据 | DC01 58.5% / DC02 55.0%；有效记录口径；证据记录 ID |
| 2:20–3:30 | 典型案例 | 滚动 D04/D14/D17；展开一条证据 | 部分得分/表现较好/记录不足；缺记录不等于未掌握；建议材料/顺序/提示/调整 |
| 3:30–4:10 | 成果包 | 点击“导出全部成果包”；展示文件列表 | Task1/2/3、案例、质量、字段说明、manifest、源数据副本 |
| 4:10–4:30 | 数据与报告 → 导入赛题数据 | 展示入口（不必实际导入） | 独立评测数据可导入；校验/预览/确认/回滚 |
| 4:30–4:45 | 回 Task1 或数据质量 | 停留 | 模拟数据声明、未接 OCR/大模型声明、数据安全 |

## 三、录屏后检查

- [ ] 时长 ≤5:00（建议 4:30–4:50）；
- [ ] 声音清晰，无环境噪音/手机通知；
- [ ] 画面无真实个人信息；只出现官方模拟数据；
- [ ] 顶栏显示“赛题数据”；
- [ ] 三项任务各出现一次；三名案例均出现；成果包文件名可见；
- [ ] 无“页面渲染失败/undefined/[object Object]”；
- [ ] 不宣称真实 OCR/大模型/真实教学成效；
- [ ] 输出 MP4（H.264，1920×1080 或 1280×720，≤500MB）。

## 四、MP4 导出建议

- 工具：OBS 录制 MP4（H.264）或 Windows 录屏；
- 帧率 30fps；码率 4–6 Mbps；
- 若文件过大，用剪辑软件压缩到 200MB 内；
- 命名：`知微智学_演示视频_团队名_日期.mp4`；
- 录后回放一遍，确认无隐私、无错误提示、无未实现功能。

## 五、不要做的事

- 不要用截图合成/幻灯片冒充 MP4；
- 不要剪辑出系统未实现的功能；
- 不要在视频中展示真实学生信息或本地路径；
- 不要超时（>5:00 视为不合规）。
