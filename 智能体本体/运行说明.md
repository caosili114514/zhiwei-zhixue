# 运行说明

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（其他系统可用 Node 命令运行） |
| Node.js | 建议 18+（仅用于启动本地静态服务；无 npm 依赖） |
| 浏览器 | Microsoft Edge / Chrome 桌面版（推荐最新版） |
| 网络 | 不需要外网；不下载依赖、不调用外部 API |
| 数据库/账号 | 不需要 |

## 2. 启动方式

### 方式 A：双击（最简单）
- 双击 `智能体本体/启动智能体.bat`；
- 脚本在 `127.0.0.1:5178` 启动服务并自动打开浏览器；
- 关闭命令行窗口即停止服务。
- 若本机未安装 Node.js：脚本会改为直接打开 `源代码/index.html`（file:// 模式；赛题数据模式仍建议用本地服务）。

### 方式 B：命令行
```bash
cd 智能体本体/源代码
node server.mjs
```
看到 `知微·智学 原型已启动：http://127.0.0.1:5178/` 即成功。

自定义端口：
```powershell
$env:PORT=5188
node server.mjs
```

### 方式 C：直接打开文件
双击 `智能体本体/源代码/index.html` 可用 `file://` 打开（演示模式兼容）。赛题数据模式的导入/导出功能建议通过本地服务访问，避免浏览器 file:// 限制。

## 3. 访问入口

| 入口 | 地址 |
|---|---|
| 首页（默认学生） | `http://127.0.0.1:5178/` |
| 赛题成果（评委主入口） | `http://127.0.0.1:5178/index.html?role=teacher&data=official#/teacher/contest` |
| 赛题教师工作台 | `http://127.0.0.1:5178/index.html?role=teacher&data=official#/teacher/dashboard` |
| 赛题学生端 | `http://127.0.0.1:5178/index.html?role=student&user=D01&data=official#/student/home` |
| 演示模式教师端 | `http://127.0.0.1:5178/index.html?role=teacher#/teacher/dashboard` |

## 4. 首次体验步骤（5 分钟）

1. 打开赛题成果入口；确认顶栏徽标为“赛题数据”。
2. 教师端 → 赛题成果 → Task1 查看主题/指标/课标/教材/题目/材料。
3. Task2 查看 DC01/DC02 对比与数据质量报告；选择 D04 查看个体指标与证据。
4. 典型案例查看 D04/D14/D17；展开证据与建议。
5. 成果包导出（浏览器下载）。
6. 右上角用户菜单可切换教师/学生、DC01/DC02、演示/赛题数据、重置当前模式。
7. 学生端：`?role=student&user=D01&data=official#/student/home`，查看学习主页/练习/档案/报告。

## 5. 停止与重置

- 停止：关闭命令行窗口，或 `Ctrl+C`。
- 重置当前模式：右上角用户菜单 → “重置赛题数据/重置演示数据”。
- 恢复赛题数据上一版本：数据与报告页 → “恢复赛题数据上一版本”（仅本机导入后可用）。
- 浏览器本地数据清除：开发者工具 → Application → Local Storage，删除 `zwz.*` 键；或使用菜单重置。

## 6. 常见问题

**Q：双击 bat 后没打开浏览器？**  
手动访问 `http://127.0.0.1:5178/`；确认 Node 已安装、端口未被占用。

**Q：页面显示“页面渲染失败”？**  
刷新；或用户菜单重置对应模式；检查浏览器控制台具体错误。

**Q：赛题数据模式没有数据？**  
确认 URL 带 `?data=official`；或在用户菜单切到“赛题数据”。首次进入会从内置 `data/official/` 构建。

**Q：能离线吗？**  
可以；本包无外网依赖。node 只用于本地静态文件服务。

**Q：为什么部分按钮显示“模拟解析/本地规则”？**  
这是如实标注：项目未接入真实 OCR/大模型，避免过度承诺。
