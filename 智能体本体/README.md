# 知微·智学 · 智能体本体

> 独立、可运行、可体验的“学情诊断与个性化学习智能体”本体包。
> 本目录是**智能体本体**（程序 + 源代码 + 运行/配置/数据/测试说明）；比赛设计方案、成果包、PPT、视频等属于**比赛成果材料**，见项目根目录 `比赛交付/`。

## 1. 这是什么

面向七年级数学的规则驱动学情诊断智能体：
- 连接**课程要求 / 观察指标 / 题目 / 作答记录 / 评分点 / 学习材料**；
- 学生端：学习主页、练习、档案、学情报告；
- 教师端：工作台、班级分析、个体档案、复核中心、试卷导入、作业批改、教学助理、赛题成果；
- 数据：原演示模式 + 官方赛题数据模式（独立存储）；
- 诊断可解释、证据可追溯；未作答/待评分/异常不会直接判为“错误/未掌握”；
- **未接入真实大模型/OCR/后端**：教学助理为本地规则应答，试卷解析为模拟解析，界面已明确标注。

## 3. 快速开始（评委最短路径）

### 方式 A：双击
双击 `启动智能体.bat`（或 `源代码/启动知微智学.bat`），浏览器打开 `http://127.0.0.1:5178/`。

### 方式 B：命令行
```bash
cd 智能体本体/源代码
node server.mjs
# 访问 http://127.0.0.1:5178/
```
> 无需 `npm install`、无构建、无数据库、无 API Key。需要 Node.js（建议 18+）与 Edge/Chrome 桌面浏览器。

### 体验入口
- **评委主入口（赛题成果）**：`http://127.0.0.1:5178/index.html?role=teacher&data=official#/teacher/contest`
- 赛题教师工作台：`...?role=teacher&data=official#/teacher/dashboard`
- 赛题学生端：`...?role=student&user=D01&data=official#/student/home`
- 演示模式：`...?role=teacher#/teacher/dashboard`（原 11 学生/206 记录）

详细步骤见 `演示入口说明.md`；完整闭环：数据导入 → 学生记录/作答 → 诊断 → 证据 → 建议/教学调整 → 导出成果。

## 5. 数据与模式

- **演示数据**：11 名学生 / 206 条作答；全部虚构，仅演示。
- **赛题数据**：官方模拟数据 40 名学生（DC01 21 / DC02 19）/ 806 条原始作答 / 54 题 / 2 节点；分析记录 799（7 个修订事件合并）；未作答 5、待评分 6（原始）。
- 两模式独立 localStorage：演示 `zwz.db.v1`，赛题 `zwz.db.official.v1`；互不污染。
- 支持“数据与报告 → 导入赛题数据”导入同 schema 的 5 张 CSV/JSON；校验、预览、确认、回滚；**不覆盖官方原始文件**。
- 不含真实学生个人信息。

## 7. 重要限制（请如实向评委说明）

1. **规则系统，不是大模型**：诊断/建议由规则和统计生成；助教为本地规则应答。
2. **模拟 OCR**：试卷导入页面为模拟解析，不读取真实 PDF/图片内容。
3. **无后端/登录**：数据保存在本机浏览器；教师/学生身份为本地切换，不是真实账号体系。
4. **无真实独立评测成绩**：官方独立评测数据未提供；5 人迷你数据集是结构适配测试，不是评测结果。
5. **MP4 不在本包**：演示视频需按 `比赛交付/录屏操作手册.md` 人工录制。
6. **无头打印偶发空白页**：正式打印建议手工操作并目检。
7. 官方成果包模板未提供；当前字段规范为项目自定义。
