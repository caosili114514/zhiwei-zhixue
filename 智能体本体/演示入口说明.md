# 演示入口说明（评委体验路线）

## 0. 启动
```bash
cd 智能体本体/源代码
node server.mjs
```
或双击 `智能体本体/启动智能体.bat`。默认地址 `http://127.0.0.1:5178/`。

## 1. 身份入口与评委主入口
**首次访问** `http://127.0.0.1:5178/`：先看到身份入口，选择“学生体验 / 教师体验 / 评委快速体验”。不自动分配身份。

**评委快速体验**：在身份入口点击“评委快速体验” → 确认面板显示“教师演示身份 + 赛题数据 + DC01” → 进入赛题成果。
**直达（明确身份）**：
`http://127.0.0.1:5178/index.html?role=teacher&user=T01&data=official#/teacher/contest`

进入后确认：
- 顶栏徽标为“赛题数据”，用户菜单显示当前教师演示身份；
- 页面标题“赛题成果”，四个 Tab：Task1 / Task2 / 典型案例 / 成果包。

## 2. 5 分钟体验路线

### 2.1 Task1 学习内容与要求（约 40 秒）
- 查看“主题/观察指标/课标页/教材页/题目/学习卡/教材切片”表；
- 展开“学习卡与教材切片清单”；
- 口播：T01–T03、T01I1–T03I3 与 CR01–CR03 的对应关系。

### 2.2 Task2 数据质量与双班分析（约 60 秒）
- 切换到 Task2；
- 查看 DC01/DC02 记录、有效记录、得分率、待评分/未作答/异常；
- 展开“数据质量报告”：7 个修订事件、3 条分数异常、1 条节点越界、5 条未作答、6 条待评分（原始）；
- 强调：未作答/待评分不判错；异常标记不静默修正。

### 2.3 个体分析与证据（约 50 秒）
- 学生下拉选择 D04；
- 查看各指标得分率/状态，展开证据记录；
- 说明证据 ID 可回溯到原始作答记录、题目、评分点。

### 2.4 三名典型案例（约 60 秒）
- 切到“典型案例”；
- D04 部分得分、D14 表现较好、D17 记录不足；
- 展开一条证据，查看建议中的学习卡/教材/练习题、顺序、提示、调整条件、后续观察；
- 强调：记录不足 ≠ 未掌握。

### 2.5 成果包与导入（约 40 秒）
- 切到“成果包”，查看文件清单；点击“导出全部成果包”；
- 进入“数据与报告”，展示“导入赛题数据”入口（如评委要求，可实际选择 5 张 CSV 预览后取消，不改变数据）；
- 说明：独立评测数据可用同一入口导入，校验/预览/确认/回滚。

### 2.6 切换与权限（约 30 秒）
- 右上角用户菜单：切换教师/学生、DC01/DC02、演示/赛题数据；
- 学生端入口：`...?role=student&user=D01&data=official#/student/home`；
- 说明学生只能看自己的数据；教师看当前班级。

## 3. 完整闭环（若时间充足）

```
数据导入（赛题数据/独立数据）
  → 学生作答/查看记录
  → 诊断（表现/状态/证据）
  → 教师复核/查看个体档案
  → 学生/教师建议（Q/L/B 材料、顺序、提示）
  → 教学调整/导出成果包
```

## 4. 重置与退出
- 用户菜单 → 重置赛题数据/演示数据；
- 数据与报告 → 恢复赛题数据上一版本（如刚导入过）；
- 关闭命令行窗口停止服务。

## 5. 评委可重点核查
- 数据对账：`比赛交付/数据对账报告.md`、`任务成果包/dataset_manifest.json`；
- 任务成果：`比赛交付/任务成果包/task1/2/3_*`；
- 代码：`智能体本体/源代码/`（59 个文件快照，含哈希清单）。
