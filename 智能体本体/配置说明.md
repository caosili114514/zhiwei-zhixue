# 配置说明

本智能体为**零依赖静态前端 + 本地静态服务器**，没有数据库连接、第三方 API、账号或密钥。以下为可配置项与本地存储约定。

## 1. 服务配置（`源代码/server.mjs`）

| 配置 | 方式 | 默认 | 说明 |
|---|---|---|---|
| 端口 | 环境变量 `PORT` | `5178` | `set PORT=5188 && node server.mjs` |
| 主机 | 环境变量 `HOST` | `127.0.0.1` | 仅本机访问；不要暴露公网 |
| 根目录 | 脚本所在目录 | `源代码/` | 静态文件根 |
| 缓存 | 代码固定 | `no-cache` | 开发/演示避免旧文件 |

无 `.env`、无密钥、无 Token、无数据库。**不要把本机路径、账号、真实学生数据写入任何配置文件。**

## 2. URL 参数

| 参数 | 可选值 | 作用 |
|---|---|---|
| `role` | `teacher` / `student` | 直接进入教师/学生身份 |
| `user` | 学生编号或教师编号（如 `D01`、`T01`） | 指定登录身份 |
| `data` | `official` / 省略 | `official` 使用赛题数据模式；省略为演示模式 |

示例：
- `?role=teacher&user=T01&data=official#/teacher/contest`
- `?role=student&user=D04&data=official#/student/archive`

## 3. 本地存储键（localStorage）

| 键 | 用途 |
|---|---|
| `zwz.db.v1` | 演示模式数据 |
| `zwz.session.v1` | 演示模式会话 |
| `zwz.db.official.v1` | 赛题模式数据 |
| `zwz.session.official.v1` | 赛题模式会话 |
| `zwz.db.official.backup.v1` | 赛题数据导入前备份（用于恢复上一版本） |

清除方式：用户菜单重置；或浏览器 Application → Local Storage 删除对应键。两模式数据独立，互不污染。

## 4. 数据源配置

- 内置赛题数据：`源代码/data/official/*.csv`（只读副本）+ `源代码/js/data/official-data.js`（生成数据）。
- 交互式导入：教师端“数据与报告 → 导入赛题数据”，选择 5 张 CSV 或含 `tables` 的 JSON；不写回源 CSV。
- 重新生成内置数据：在项目根目录执行 `node _dsh_work/gen-official-data.mjs`（仅在开发树使用；本包已包含生成结果，不需要执行）。

## 5. 权限与会话

- 学生只能看到自己的数据；教师可见当前班级与授权个体。
- 身份/班级切换仅是本机演示，不是真实账号认证；部署到真实环境时必须补后端鉴权。
- 不提供跨设备同步。

## 6. 公开部署注意

当前只建议本机/内网演示。若需公网体验：
1. 使用静态托管（需把 `index.html`、`css`、`js`、`data` 一起托管）；
2. 不要暴露 `server.mjs` 管理端口；
3. 不要将真实学生数据放入前端；
4. 需补充访问控制、HTTPS、隐私声明与数据删除机制。
