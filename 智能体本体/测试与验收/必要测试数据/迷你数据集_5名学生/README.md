# 迷你数据集（5 名学生）

## 用途
用于验证“智能体不依赖官方固定 40 名学生/806 条记录/DC01/DC02 规模”的结构适配能力。

## 内容
- 学生：D01–D05（均属 DC01），5 名；
- 作答：110 条原始记录（108 个作答事件）；
- 课程要求：9 条（完整）；
- 题目与材料：65 行（完整）；
- 测验节点：2 个（完整）；
- 字段说明：官方原样副本。

## 运行
```bash
cd 智能体本体/测试与验收
node 验证迷你数据集.cjs
```
预期：校验通过、构建 5 名学生/1 个班/108 条分析记录，且不出现 40/799 的官方固定值。

## 声明
- 本数据集由官方模拟数据筛选生成，**不是赛方独立评测数据**；
- 不用于得出教学评价或比赛成绩；
- 不覆盖、不修改 `源代码/data/official/` 原始数据。
