# 测试说明

## 1. 测试目标

验证智能体本体在**独立目录**下可运行、可导入、可诊断、可导出，并且不依赖固定官方样本规模。

## 2. 测试环境

- Windows 10/11；Node.js 24（建议 18+）；
- Edge / Chrome 桌面版；
- 无外网、无 npm 依赖、无数据库。

## 3. 测试命令

在 `智能体本体/源代码/` 下：
```bash
node tests/check-data.mjs        # 原演示数据 53 项（含写循环/权限/异常/打印数据）
node tests/check-official.mjs    # 官方数据/质量/导入回滚/成果 15 项
node tests/check-identity.mjs    # 身份入口/学生权限/退出 16 项
node tests/smoke.mjs             # 12 路由 + 权限守卫 2/2
node tests/smoke.mjs --print     # 打印复核 3/3
```
在 `智能体本体/测试与验收/` 下：
```bash
node 校验源代码.cjs               # 54 个源代码文件完整性哈希
node 验证迷你数据集.cjs           # 5 名学生结构适配（非赛方成绩）
```

## 4. 测试数据

- 官方数据：`源代码/data/official/`（40 学生 / 806 原始记录 / 2 节点）。
- 迷你数据集：`测试与验收/必要测试数据/迷你数据集_5名学生/`（5 学生 / 110 条作答 / 1 班），用于验证不硬编码官方规模、缺失数据不误判。
- 迷你数据不写回官方数据、不覆盖原始 CSV。

## 5. 验收标准

1. `check-data` 全部通过；
2. `check-official` 全部通过；
3. 12 路由全部通过、权限 2/2；
4. 打印 3/3（无头打印偶发空白页时重跑并记录，不视为彻底修复）；
5. 源代码哈希 52/52 一致；
6. 迷你数据集 5 学生可校验、可构建，且构建结果不是 40/799；
7. 手动体验：能进入学生/教师端、两种数据模式、赛题成果 4 Tab、导入/导出可用。

## 6. 已知测试限制

- `smoke.mjs` / 打印测试依赖本机 Edge 与无头打印；不同机器可能有时序差异。
- 未接入真实 OCR/大模型，相关测试只验证模拟/规则逻辑，不验证模型能力。
- 独立评测数据未提供，无法做真实独立评测对照。
