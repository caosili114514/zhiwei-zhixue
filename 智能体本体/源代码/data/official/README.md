# 官方模拟学情数据（比赛用）

- 来源：主办方《【赛题材料】智慧学伴》的 `4_赛题数据/模拟学情数据/`（公开模拟数据）。
- 用途：仅用于本次比赛；学生、班级、成绩均为模拟，不含真实学生个人信息。
- 文件：`课程要求.csv`、`题目与材料.csv`、`模拟学生.csv`、`测验节点.csv`、`作答记录.csv`、`字段说明.csv`，原样复制，禁止手改。
- 运行时代码：`js/data/official-data.js` 由 `_dsh_work/gen-official-data.mjs` 自动生成；`js/data/official.js` 负责转换为应用 state。
- 重新生成：`node _dsh_work/gen-official-data.mjs`（读取本目录 CSV）。
- 数据规模：40 学生 / 2 班 / 54 题 / 65 材料行 / 2 节点 / 806 条作答（原始）；7 个作答事件含修订版本。
- 已知质量问题（必须在报告中保留、不得静默修正）：3 条分数异常、1 条节点越界、5 条未作答、6 条待评分（原始计数）。
- 数据口径与处理详见 `_dsh_work/比赛交付/任务成果包/README.md` 与 `data_quality_report.*`。
