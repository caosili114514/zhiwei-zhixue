# 知微·智学 · 七年级数学学情诊断与个性化学习智能体（可交互原型）

> 面向七年级数学的学情诊断与个性化学习智能体。以「可靠、可解释、可复核的学情诊断」为核心，连接**学生学习支持**与**教师教学决策**。
>
> 支持两种数据模式：**演示数据**（11 名学生/206 条作答，全部虚构）与**赛题数据**（主办方模拟数据：40 名学生/806 条原始作答/2 个班，独立存储）。所有学生、班级、成绩均为模拟，不含真实学生个人信息。
>
> 📦 **智能体本体独立交付包**：`智能体本体/`（可运行程序 + 源代码 + 运行/配置/数据/测试/演示入口）；比赛成果材料：`比赛交付/`。

## 一、快速开始

### 方式 A：双击（推荐，最省事）
双击项目根目录的 **`启动知微智学.bat`**：脚本会在本机 `127.0.0.1:5178` 启动静态服务并自动打开浏览器。关闭命令行窗口即停止服务。

### 方式 B：直接打开网页
双击 **`index.html`**，即可用浏览器直接打开（采用经典脚本，兼容 `file://` 协议）。此方式下数据仍保存在本机浏览器中。

### 方式 C：命令行（开发者）
```powershell
cd "E:\人工智能+创新大赛"
node server.mjs
# 然后访问 http://127.0.0.1:5178/
```

> 无需 `npm install`、无需任何依赖与构建步骤。推荐使用 Microsoft Edge / Chrome 桌面浏览器；页面适配常见桌面与平板宽度。

### 身份入口（首次进入必须选择）
- 直接打开 `index.html`（不带身份参数）会进入**身份入口**：学生体验 / 教师体验 / 评委快速体验，不自动分配身份。
- 学生需选择具体学生；教师需选择班级；评委快速体验固定为“教师演示身份 + 赛题数据 + DC01”。

- `?role=` 只预选身份入口角色，不会自动登录；`?user=` 是明确身份，可直接进入对应演示。

## 四、核心闭环（产品要解决的问题）

```
教师导入题目/试卷 → 模拟解析预览 → 教师确认题目、知识点与评分规则 → 布置任务
        ↓
学生完成练习并提交作答 → 规则判分（自动 / 建议复核 / 暂无法判阅）
        ↓
诊断引擎综合「题目映射 + 作答记录 + 提示使用 + 识别质量 + 记录数 + 教学范围」
        ↓
学生端：即时诊断反馈 + 分层伴学提示（知识点 → 思路 → 步骤 → 完整解析）
教师端：班级学情分析 + 个体档案 + 教学助理（带依据的参考建议）
        ↓
教师复核判分 / 确认或修正诊断 / 标记暂无法判断 → 新数据进入阶段追踪
        ↓
导出班级/个体报告与结构化诊断数据 → 下一轮教学与练习
```

### 教育安全规则（实现层面强制）
- 单次错误**不会**推出"学生不会"：诊断需结合记录数、覆盖、识别质量与其他可能原因；
- 记录数不足 → 「初步判断」；无有效记录 / 记录待复核 → 「暂无法判断」/「待复核」；仅「证据充分」才给出明确结论；
- 区分「尚未学习 / 不在当前教学范围」与「学习后仍有困难」；
- 缺失记录**不等同于答错**；
- 过程题只做辅助批阅，必须教师复核，不得伪装自动批改；
- 所有 AI/OCR/分析能力均为**规则实现或模拟**，界面上明确标注，不伪造真实模型。
- 措辞不使用"失败 / 差生 / 排名"等标签，采用可改善、支持性表达。

## 五、技术实现说明

| 关注点 | 实现方式 |
|---|---|
| 技术栈 | 原生 HTML / CSS / JavaScript（经典 script，非 ES Module），无构建、无依赖 |
| 路由 | `location.hash`（如 `#/teacher/analysis`），含角色越界保护与深链参数 |
| 状态管理 | `js/core/store.js` 单一数据源 + `localStorage` 持久化 + 变更订阅；所有写操作经 action 并写审计日志 |
| 渲染 | `html`` 模板自动转义 + 组件库拼装 DOM + 页面 `mount()` 绑定事件 |
| 图表 | 手写 SVG（横条 / 堆叠 / 折线 / 热力图 / 环形 / 迷你图），自带标题、单位、口径说明 |
| 诊断 | 规则引擎：按知识点聚合记录 → 计算表现（独立完成 / 提示后完成 / 反复尝试 / 仍需巩固 / 尚未学习 / 记录不足）与状态，并输出证据 quotes、覆盖率、建议 |
| 判分 | 客观题按明确答案规则自动判分（含全角/符号/分数归一化、多答案接受列表）；过程题 `suggested` 不定分；识别质量低/空白 `unjudged` |
| 导入导出 | CSV（引号/BOM 解析）、JSON、打印（打印样式）；导入含字段映射、预览与质量检查 |
| 可替换性 | `services/` 均为独立服务层，接口固定；接入真实 OCR / 大模型 / 后端时只需替换实现，页面不变 |

## 八、已知限制

1. 无后端：数据保存在浏览器 `localStorage`，换浏览器/清缓存后回到初始演示数据；不同设备之间不共享。
2. OCR、真实模型、真实批改均未接入，相关页面均标注「模拟 / 待接入」。
3. 教材版本与课程标准为示例配置，具体章节以教师确认为准。
4. 图表与诊断基于 11 名学生、206 条作答的小样本演示数据，样本量不足处已显式提示"数据不足"，不作过度推断。
5. 原型聚焦桌面浏览器；窄屏下导航折叠、表格横向滚动，但复杂分析页在手机竖屏上的体验未做专项优化。
